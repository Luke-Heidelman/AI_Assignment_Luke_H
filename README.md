What concrete benefits did you see by utilizing AI to help you make the notebook? 
The most concrete benefits to using AI was mostly speed and making the template for the final version of each graph. AI would generate the base code needed for the graph, and I would then be able to easily tweak it to display the way I wanted it to. The speed was also nice, instead of needing to look up how to format code and what code was needed, most of the code was written for me and tweaks were very small details that either a quick prompt would fix or simply just myself being able to change a quick line.

What dangers do you see for someone using AI to make this notebook without learning data science properly? Give concrete examples. 
If a person had done this project without knowing data science, or even the project itself very well, the worst issue is that any interpretation or conclusion drawn from the AI created graphs is that it may be wrong or misinterpreted. AI makes many mistakes, and these may not be caught if the user doesn't know the data science to verify the AI's work.
